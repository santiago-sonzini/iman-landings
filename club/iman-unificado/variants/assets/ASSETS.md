# Identity variant assets

- `logo-v1.png`: transparent native-resolution extraction of the supplied first identity PDF artwork (1751 × 710). That PDF embeds flattened page images; no vector logo was available. The PNG preserves the wordmark rather than recreating it with text.
- `logo-v1.svg`: optional self-contained SVG wrapper of the same PNG.
- `logo-v2.svg`: exact vector logo outline and gradient extracted from the supplied second identity PDF.
- `favicon-v1.svg`, `favicon-v2.svg`: the corresponding extracted accent isolated on the dark brand background.
- `share-v1.png`, `share-v2.png`: 1200 × 630 social previews using the extracted wordmarks.
- `fonts/inter-latin.woff2`: Inter variable font, normal, 300–900, Latin including Spanish.
- `fonts/geist-mono-latin.woff2`: Geist Mono variable font, normal, 400–600, Latin including Spanish.

Fonts are self-hosted from Google Fonts; their SIL Open Font License texts are included in `fonts/`.
