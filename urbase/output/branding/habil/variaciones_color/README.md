# HÁBIL — Variaciones de color del diseño aprobado

Se conserva la propuesta Ingenio Industrial elegida por el usuario. La edición cambia solamente el acento naranja, sus aplicaciones y su código de color; no propone nuevos logos.

Herramienta: generación/edición de imágenes integrada (modo built-in), con la lámina aportada por el usuario como imagen objetivo. Imágenes conceptuales para comparar paletas; no archivos vectoriales finales.

- [Azul cobalto — #2F5BEA](01_azul_cobalto.png)
- [Verde petróleo — #178A7D](02_verde_petroleo.png)
- [Lima — #B6D43A](03_lima.png)
- [Bordó — #A33751](04_bordo.png)

No transparency, no haze, no tinted glow, no dark page background. No gradients in flat logos. Final output is the same landscape full board with only the accent color changed.
